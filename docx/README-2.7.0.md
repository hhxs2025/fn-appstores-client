## 📖 项目简介

FN软仓是飞牛OS上的第三方应用商店客户端，支持**多软件源聚合**。用户可自由添加自托管服务端地址，安装、体验飞牛官方应用中心没有的其他三方应用。

| 链接 | 说明 |
| :--- | :--- |
| **客户端项目地址** | [https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores) |
| **服务端镜像拉取** | `docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.5.4` |

> **v2.7.0 后端全面迁移到 Go**：单二进制、无运行时依赖、启动更快、内存更低、支持 amd64/arm64 交叉编译。

## ✨ 核心功能

| 功能模块 | 说明 |
| :--- | :--- |
| **后端 Go 重写（v2.7.0）** | 从 Python 迁移到 Go + Gin，单二进制、无运行时依赖、启动更快、内存更低 |
| **开发者星球（v2.7.0）** | 3D 球面可视化开发者，拖动旋转、滚轮缩放、悬停查看、点击进入详情 |

| **HTTPS 图片代理（v2.6.2）** | HTTPS 页面下 HTTP 图片自动转到同源代理，绕开浏览器混合内容拦截，轮播图、图标、截图正常显示 |
| **轮播图点击放大（v2.6.2）** | 首页轮播图支持点击查看大图，支持左右切换、ESC 关闭 |

| **首页看板** | 轮播图（70%）+ 公告记录列表（30%），四列快捷卡片：已安装/可更新/热度榜/新应用 |
| **公告缓存** | 首页公告数据 5 分钟内存缓存，切换页面秒开 |
| **公告记录** | 支持多条公告列表（日期 + 标题），点击弹窗查看详情（支持富文本） |
| **多源应用聚合** | 从所有启用的源拉取应用列表，自动去重（保留较新版本），卡片显示来源 |
| **软件源管理** | 添加/删除/启用/禁用软件源，源状态缓存 5 分钟 |
| **一键安装/更新** | 支持安装向导，WebSocket 实时推送下载进度；安装任务队列支持断线续传 |
| **应用列表排序** | 支持按名称、下载量、更新时间排序 |
| **安装即时刷新** | 安装完成后自动更新卡片状态 |
| **来源标识** | FN认证标识（`✅FN-`），官方源/认证三方源/自添加源视觉区分 |
| **应用类型筛选** | 应用列表支持按「全部 / Docker应用 / 原生应用」分类筛选 |
| **按源名称筛选** | 下拉选择框按来源快速过滤应用 |
| **设置中心** | 通用 / 系统 / 关于 / 统计 |
| **客户端自更新** | 设置页「检查更新」自动检测最新版本，下载 FPK 后引导用户前往应用中心手动安装 |
| **数据持久化** | `sources.json` 存储于 `TRIM_PKGVAR` 持久化目录，应用更新后用户配置不丢失 |
| **应用列表自过滤** | FN软仓客户端自身不再显示于应用列表中 |

| **端口模式降级** | 通过 `FN_SOFT_START_MODE=port` 一键切回旧模式，兼容低版本系统 |

> **v2.3.2+ 配合服务端 v2.4.0+ 使用**，支持树状聚合架构，官方源可聚合三方源应用，用户无需自行添加三方源即可发现更多应用。


## 📖 使用指南

### 访问方式

- **桌面图标**：应用中心装好后，飞牛桌面出现 FN软仓图标，点击即开
- **网关地址**：`https://你的飞牛域名/app/fn-appstores-client`
- **旧端口访问**：如通过 `FN_SOFT_START_MODE=port` 降级，仍可 `http://IP:5660` 访问

### 首页看板

- **顶部轮播图**：展示平台宣传图（占70%宽度），点击可查看大图
- **公告记录**：显示最近5条公告（标题 + 日期），点击可查看全文（5分钟缓存）
- **快捷卡片**：已安装/可更新/热度榜/新应用，点击任意应用直接查看详情

### 浏览应用

- 点击左侧导航「应用」进入应用列表
- 使用分类标签（影音/办公/下载/AI/设计/社交/网络/工具/生活/商务/教育/效率/开发/游戏）快速筛选
- 使用「Docker应用 / 原生应用」筛选器按应用类型过滤
- 使用「按源名称」下拉框按来源过滤
- 点击排序下拉框按名称、下载量或更新时间排序
- 在搜索框输入关键词查找特定应用

### 开发者星球（v2.7.0 新增）

- 点击左侧导航「开发者」进入
- 开发者以星星形式分布在 3D 球面上
- **拖动**旋转球体，**滚轮**缩放
- **悬停**星星查看开发者信息
- **点击**星星打开开发者详情（应用数、总下载、最近更新、应用列表）
- 三种颜色区分开发者类型：
  - 金色：官方开发者
  - 蓝色：认证开发者
  - 白色：个人开发者
- 窄屏（<900px）自动降级为卡片列表

### 安装应用

1. 点击应用卡片进入详情页
2. 点击「安装」按钮
3. 如应用有向导，填写配置项后确认
4. **独立进度弹窗**展示下载进度、速度、已下载/总大小
5. 安装成功后弹窗 3 秒自动关闭，卡片状态更新为「已安装」

> **v2.7.0 优化**：安装任务 30 分钟超时强制复位；独立进度弹窗更直观。

### 更新应用

- 已安装应用有新版本时，卡片显示「更新」按钮
- 点击「更新」，自动下载新版并安装

### 客户端自身更新

1. 点击左侧导航「设置」→「系统」
2. 点击「检查更新」按钮
3. 如有新版本，自动下载 FPK 文件到浏览器下载目录
4. 下载完成后弹窗提示，前往飞牛应用中心 → 手动安装 → 上传已下载的 FPK 文件

### 管理软件源

1. 点击左侧导航「源管理」
2. 查看所有已配置的源及其状态（在线/离线/已禁用）
3. 点击「添加源」，填写名称和地址
4. 点击「测试」验证连通性，确认后添加
5. 可随时启用/禁用或删除自定义源（官方源不可删除）

### 系统设置

1. 点击左侧导航「设置」
2. 切换标签页：通用 / 系统 / 关于 / 统计
   - **通用**：深色模式开关、导出日志、清除本地缓存
   - **系统**：客户端版本、系统架构、检查更新
   - **关于**：开发者、开源协议、源码仓库、交流群、聚合申请、QQ群二维码、官方源查询
   - **统计**：总应用数、已安装、可更新、已配置源

## ❓ 常见问题

<details>
<summary><b>升级到 v2.7.0 后能感知到什么变化？</b></summary>

1. **启动更快**：从 Python 迁移到 Go，启动时间从 1~2 秒降到 <100ms
2. **内存更低**：常驻内存从 ~50MB 降到 ~15MB
3. **开发者星球**：左侧导航多了「开发者」项，3D 球面可视化开发者
4. **安装更直观**：安装时弹出独立进度弹窗，大百分比数字
5. **更稳定**：安装 30 分钟超时自动复位，避免卡死
6. **功能完全一致**：应用列表、安装、更新、向导、公告、源管理等 v2.6.2 的所有功能保持不变
</details>

<details>
<summary><b>升级到 v2.6.2 后桌面没有图标？</b></summary>

1. 确认飞牛系统版本 ≥ 1.2.0401、App 版本 ≥ 1.34.0
2. 检查 `ui/config` 顶层 key 是否为 `.url`（不是 `url`）
3. 检查 `ui/config` 里 `gatewayPrefix` 和 `gatewaySocket` 是否有值
4. 检查 `manifest` 里 `desktop_applaunchname` 与 `ui/config` 中的入口 ID 是否完全一致
5. 检查 `ui/images/icon_64.png` 和 `icon_256.png` 是否存在（文件名小写）
</details>

<details>
<summary><b>HTTPS 访问时轮播图/图标不显示？</b></summary>

v2.6.2+ 已通过客户端图片代理解决。如果仍不显示：

1. 打开浏览器 DevTools → Network，筛选 `proxy-image`
2. 若无请求：检查 `index.html` 是否已替换为最新版本
3. 若返回 403：图片域名不在白名单，检查该域名是否属于已配置的软件源
4. 若返回 500：客户端拉图失败，查看 `app.log` 中「代理图片失败」日志
5. 若返回 413：单张图片超过 10MB，调整 `ImageMaxSize`
</details>

<details>
<summary><b>系统版本低于 1.2.0401 装不上？</b></summary>

统一网关要求系统版本 ≥ 1.2.0401。低版本系统可降级到端口模式：

1. `manifest` 加回 `service_port = 5660`
2. `ui/config` 改回带 `port: "5660"` 的入口，去掉网关字段
3. `cmd/main` 里把 `START_MODE` 默认值改为 `port`
</details>

<details>
<summary><b>打包时提示 `app.sock: no such device or address`？</b></summary>

源码目录有运行时残留的 Unix socket 文件，打包时无法复制。打包前清理：

```bash
find . -name "app.sock" -delete
find . -name "app.pid" -delete
find . -name "app.log" -delete
find . -name ".DS_Store" -delete
```
</details>

<details>
<summary><b>fnpack 可视化编辑器"应用入口"页一片空白？</b></summary>

编辑器 schema 不认 `gatewayPrefix` / `gatewaySocket` 字段，遇到会崩。

**不要用可视化编辑器改 config**，直接手写 `ui/config` 文件，命令行 `fnpack build` 打包。
</details>

<details>
<summary><b>开发者星球不显示？</b></summary>

- 窗口宽度需 ≥ 900px 才显示 3D 球体
- 窄屏会自动降级为卡片列表
- 如果一直没有数据，检查应用列表是否加载成功（开发者数据从 `allAppsData` 聚合）
</details>

<details>
<summary><b>安装弹窗一直不关闭？</b></summary>

- 正常安装：成功 3 秒后自动关闭
- 失败：保留弹窗，用户手动关闭
- 卡死场景：30 分钟超时强制复位，弹窗可手动关闭
- 如果按钮一直显示"安装中"，刷新页面重试
</details>

<details>
<summary><b>应用列表加载慢？</b></summary>

首次加载需从服务端拉取数据，受网络影响。后续访问会使用缓存，速度会明显提升。
</details>

<details>
<summary><b>可更新卡片显示"暂无应用"？</b></summary>

1. 确认是否有已安装应用存在新版本
2. 点击右上角「刷新」按钮强制拉取最新数据
3. 如确认有可更新应用但仍不显示，请升级至 v2.5.1+
</details>

<details>
<summary><b>截图不显示？</b></summary>

1. 确认服务端 `previews/{app_id}/` 目录下有截图文件
2. 文件命名应为 `1.PNG`、`2.PNG`（大小写敏感）
3. 确认服务端地址可正常访问
4. HTTPS 页面下检查是否为混合内容拦截，v2.6.2+ 已通过图片代理解决
</details>

<details>
<summary><b>安装失败？</b></summary>

1. 确认飞牛系统有足够的存储空间
2. 检查服务端 `apps/` 目录下是否存在对应的 `.fpk` 文件
3. 查看 `app.log` 日志获取详细错误信息
4. 如遇 WebSocket 连接问题，升级至 v2.6.1+ 可获得更好的断线重连支持
</details>

<details>
<summary><b>三方源应用来源标签显示为"FN软仓官方源"？</b></summary>

请升级客户端到 v2.3.2 及以上版本，并确保服务端为 v2.4.0 及以上版本。
</details>

<details>
<summary><b>公告内容不显示或格式错乱？</b></summary>

1. 确认服务端 `notice.json` 使用 `records` 数组格式（v2.5.0+）
2. 富文本仅支持 `<p>`、`<a>`、`<b>`、`<strong>`、`<h1>`~`<h5>`、`<br>`、`style="font-size/color"`
3. 使用 `<br>` 标签换行，而非 `\n`
</details>

<details>
<summary><b>更新客户端后，之前添加的源还在吗？</b></summary>

v2.5.1+ 已修复此问题。`sources.json` 现存储于 `TRIM_PKGVAR` 持久化目录（`/vol*/@appdata/fn-appstores-client/`），应用更新后用户添加的源不会丢失。
</details>

<details>
<summary><b>WebSocket 连接失败或安装请求丢失？</b></summary>

v2.6.1+ 已优化 WebSocket 连接管理：
1. 统一 WebSocket 实例，避免双定义冲突
2. 自动适配 HTTP/HTTPS 协议
3. 断线后自动重连（指数退避，最大 10 次）
4. 安装请求加入任务队列，连接恢复后自动续传

v2.7.0 进一步增加 30 分钟超时强制复位。
</details>

<details>
<summary><b>网络抖动时页面空白或加载失败？</b></summary>

v2.6.1+ 已增强错误降级：
