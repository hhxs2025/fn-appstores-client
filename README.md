## 📖 应用简介

FN软仓是飞牛 OS 上的第三方应用商店客户端，支持**多软件源聚合**。它不仅仅是一个软件仓库，更是一个**“可无限裂变”的独立应用分发平台**。用户可以自由添加自托管服务端地址，浏览、安装、更新飞牛官方应用中心没有的三方应用。

- **项目地址**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)
- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.1`
- **平台**：飞牛 OS
- **架构**：x86 / ARM 双架构兼容
- **开源协议**：MIT

> **架构与机器码识别说明**：客户端会优先读取飞牛底层系统注入的机器码（`TRIM_SYS_MACHINE_ID`）作为设备唯一标识，确保**重装系统后不产生虚假新设备**。系统架构（如 `fnos-amd64`）通过请求头精准上报，解决 WebView 读取 `UA` 显示 Win32 的历史遗留问题。

> **✅ v2.10.0 核心变化：双模式初始化与极客纯净体验**。
> 本次更新正式打通了“任何人拿服务端即可另起炉灶”的底层闭环。新增**首次启动双模式引导**，极客玩家可彻底禁用内置官方源，拥抱纯净；底层加入**源管理越权拦截**与**独立自更新隔离**，即使禁用官方源依然能收到软件更新，确保客户端永不“断联”。

## ✨ 核心功能

### 全新双模式引导与安全加固 (v2.10.0 新增)

- **双模式初始化**：首次安装启动时，客户端会主动弹窗引导：
  - **用户模式**：开箱即用，默认启用官方源。
  - **极客模式**：彻底禁用内置官方源，需手动添加自建服务端地址。
- **源管理权限加固**：在应用未完成初始化前，后端直接拦截修改/添加源的越权请求，保证系统配置不被恶意劫持。
- **独立自更新隔离**：即使极客模式在列表里禁用了官方源，客户端自更新检测接口（`/api/check-update`）依然会向官方源发起请求，确保客户端永远能收到版本修复与新功能更新。
- **深度的数据隔离**：切换模式时，自动清理本地缓存、公告已读、推送记录等脏数据，彻底告别不同源之间“幽灵应用”串台的问题。

### 应用管理

- **多源聚合**：从所有启用的软件源并发拉取应用列表，按 `id@platform` 自动去重
- **树状聚合**：官方源可聚合多个三方源应用，无需手动添加即可发现更多应用
- **分类筛选**：15 个固定分类 + Docker/原生类型筛选 + 按源筛选
- **排序**：支持按名称、**开发者**、下载量、更新时间排序
- **全局搜索**：侧边栏顶部搜索框，任意页面可直接搜索
- **架构自动适配**：启动时检测本机架构（`runtime.GOARCH`），不兼容的应用自动过滤

### 首页轮播与动态交互

- **自动轮播与悬停暂停**：轮播图支持 5 秒自动切换，底部小圆点同步高亮。鼠标移入轮播区域自动暂停播放，移出恢复。
- **定向交互跳转**：无缝承接服务端 `notice.json` 下发的配置协议（`图片URL|跳转目标`）。点击轮播图可直接打开**特定应用详情**（如 `app:fn-appstores-client`）、**指定分类列表**（如 `tag:影音`）、**外部链接**（如 `url:https://...`）或**指定页面Tab**（如 `tab:settings`）。
- **静默刷新机制**：新增 5 分钟缓存 TTL。用户切离首页再切回时，后台会静默拉取最新公告和轮播图，页面不闪烁白屏。

### 系统级定向消息推送

- **多端触达机制**：支持 WebSocket 实时接收服务端推送，同时在客户端启动时通过 `/api/push/pending` 主动拉取离线期间的未读消息，确保不漏看。
- **三种消息形态**：
  - **轻提示 (Toast)**：停留长达 10 秒，且**鼠标悬停时自动暂停倒计时**，排版清晰，适合日常运营通知。
  - **强弹窗 (Modal)**：必须在页面中央点击“我知道了”才能关闭，适合重要版本发布或紧急故障通告。
  - **强制更新 (Force Update)**：直接锁定页面，提供“一键下载最新 FPK”引导。下载完成后提示去飞牛应用中心覆盖安装，解决旧版本严重 Bug 或安全漏洞。
- **本地去重与防骚扰**：接收过的推送会被记录在浏览器本地，刷新页面不会重复弹出。

### 应用安装与更新（极速下载引擎）

- **双段式安装链路**：
  - **极速下载段**：客户端调 `/api/download`，后端下发基于实测速度动态排序的候选线路。客户端采用**断点续传机制**，跨线路切换时无需从头下载；引入 **8 秒首包看门狗**、**30 秒 stall 停滞检测**，以及**首块 50KB/s 极速秒切**逻辑，遇到龟速假死节点瞬间抛弃并切换，告别下载卡 0%。
  - **官方安装段**：FPK 下载到本地后，前端调飞牛官方 `app-center/v1` 完成安装——`download/task` 登记本地文件 → `install/info` 预检依赖与读取向导 → `install/task` 提交安装 → `install/status` 轮询获取真实进度。
- **安装前依赖预检**：安装前调 `/api/read-manifest` 解压 FPK 读 `install_dep_apps`，主动与飞牛已安装应用对比，缺失依赖直接弹窗引导。
- **平滑更新**：走飞牛 `update/task` 更新接口，系统自动保留用户数据并平滑升级，不再使用"卸载 → 重装"粗暴流程。

### 底层管理与强力修复

- **智能状态联动**：应用详情页打开时，自动调用底层接口查询真实运行状态。运行中只显示「停止」，已停止只显示「启动」。
- **强力修复（专治幽灵应用）**：针对部分设备因底层数据库卡死导致的"应用中心有，桌面无图标/点不开"现象。一键绕过飞牛 CLI 安全拦截，强制物理清理底层目录与进程，并重新注册安装。
- **配置备份与恢复**：支持将 `/vol/@appdata/{app_id}` 下的所有用户配置打包为 `.zip` 下载；上传 `.zip` 备份文件自动解压覆盖并重启应用，实现配置无损迁移。

### 设备与架构精准识别

- **机器码采集**：读取系统底层 ID，配合服务端实现 100% 精确的设备活跃统计与去重。
- **全链路 Header 注入**：客户端向服务端发起请求时（拉应用、看公告、拉消息），自动附带 `X-Client-ID`、`X-Device-Type`（如 `fnos-amd64`）和 `X-App-Version`。
- **真实架构显示**：调用 `/api/sysinfo` 获取 NAS 真实 CPU 架构，彻底告别浏览器兼容性导致的显示错误。

### 一键诊断日志

- **位置**：应用详情页新增「导出日志」按钮。
- **内容**：自动收集飞牛底层的安装状态、运行状态，以及 `@appdata` 目录下最后 500 行 `.log` 日志。

## 🧭 界面介绍

左侧导航栏共 5 项，窄屏折叠为单图标，移动端折叠为汉堡菜单。

### 🏠 首页
- **顶部轮播图**：支持自动轮播与悬停暂停；点击支持跳转应用、分类或外链。
- **公告记录**：最近 5 条公告，未读项左侧显示红点。
- **四列快捷卡片**：已安装 / 可更新 / 热度榜 Top 10 / 新应用。

### 📦 应用
- **工具栏**：状态 + 应用数 + 排序 + 手动安装 + **一键强刷**。
- **应用详情**：包含大图标、元信息栏、更新内容、应用介绍、预览轮播、评分、一键启动/停止、修复、配置备份恢复等全套工具。

### ✨ 开发者
- 3D 球面可视化开发者，星星大小与应用数挂钩。支持拖动旋转、滚轮缩放、悬停查看。

### 🔗 源管理
- 添加、删除、启用、禁用、测试三方源。在“极客模式”下作为核心入口。
- 官方源地址隐藏显示，防止被恶意抓取。

### ⚙️ 设置
- **通用**：深色模式、导出日志。
- **收藏**：集中管理收藏的应用。
- **系统**：客户端版本、真实系统架构、检查更新。

## 🖥️ 服务端信息

客户端需要配合 **FN软仓服务端** 使用，服务端负责聚合应用列表、下发候选下载地址、维护加速器规则、公告和轮播图。

- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.1`
- **服务端仓库**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)

服务端 v2.10.1 的核心能力：

- **动态候选下发**：返回经过健康检查和实测测速后的 `download_urls` 数组。
- **FPK 下载任务管理**：提供后端多线路下载、断点续传能力。
- **加速器健康检查**：智能探测速度与状态，支持降级/离线兜底。
- **轮播图协议支持**：支持下发带跳转目标的数据。
- **定向消息推送**：支持向指定版本、架构或特定设备 ID 发送强更指令。
- **开发者纯在线托管**：开发者无需维护仓库，数据保存在服务端本地。
- **设备精准统计**：支持在线状态判定与 CSV 导出。
