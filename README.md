## 📖 应用简介

FN软仓是飞牛 OS 上的第三方应用商店客户端，支持**多软件源聚合**。它不仅仅是一个软件仓库，更是一&#x4E2A;**"可无限裂变"的独立应用分发平台**。用户可以自由添加自托管服务端地址，浏览、安装、更新飞牛官方应用中心没有的三方应用。

**项目地址**：<https://gitee.com/hhxs2025/fn-appstores>

**服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.4`

**平台**：飞牛 OS

**架构**：x86 / ARM 双架构兼容

**开源协议**：MIT

> **架构与机器码识别说明**：客户端会优先读取飞牛底层系统注入的机器码（`TRIM_SYS_MACHINE_ID`）作为设备唯一标识，确保**重装系统后不产生虚假新设备**。系统架构（如 `fnos-amd64`）通过请求头精准上报，解决 WebView 读取 UA 显示 Win32 的历史遗留问题。

> **✅ v2.11.1 核心变化：。  
> 修复因升级带来的手动安装入口失效问题+新增fpk、图标、预览图缓存提升加载体验+设置-系统下新增缓存清理入口

## ✨ 核心功能

### 下载引擎 2.0：服务端实时选线 + 无状态尝试（v2.11.0 重构）

**服务端实时选线**：安装时客户端拿到的第 1 条候选是服务端 `/apps/` 本地代理入口——服务端在收到请求的**那一瞬间**根据健康探测结果现场选择最优加速线路并 302 重定向，天然就是"最新地址"，无需任何刷新操作。

**候选顺序完全由服务端决定**：客户端按服务端基于健康度/实测速度排好序的候选列表**从头到尾依次尝试**，本地不做任何跳过、不做任何否决。

**彻底移除本地失败记录**：不再维护"加速线路连败黑名单"，一次网络抖动不会让任何线路被打入冷宫，连续安装永远顺畅，无需删文件、无需点刷新。

**整轮时间预算**：单次安装整体限时 25 秒，全部线路异常时快速给出明确提示，绝不无限等待。

**双看门狗护航**：单线路 **2 秒首包看门狗** + **5 秒停滞检测**，死链秒切不卡进度。

**跨线路断点续传**：线路切换时已下载部分不浪费，从断点继续。

### 精准下载统计（v2.11.0 新增）

下载校验（文件完整性）**通过之后**才向服务端上报计数，杜绝虚高下载量。

### 图标显示修复（v2.11.0 新增）

解决部分局域网 / HTTPS 环境下应用图标裂图问题，图片统一经客户端代理转发。

### 连接假离线修复（v2.11.0 新增）

底层适配鉴权风控，源不再出现"假离线"误判。

### 卸载数据真正可清除（v2.11.0 新增）

卸载向导勾选"清除数据"后，卸载脚本会停进程 → 清空 `@appdata` 数据目录 → 清理 data-share 共享目录与残留 socket。内置三重路径校验，杜绝误删；未勾选则完整保留用户数据。

### 应用管理（继承 2.10.0）

**多源聚合**：从所有启用的软件源并发拉取应用列表，按 `id@platform` 自动去重。

**树状聚合**：官方源可聚合多个三方源应用，无需手动添加即可发现更多应用。

**分类筛选**：15 个固定分类 + Docker/原生类型筛选 + 按源筛选。

**排序与搜索**：按名称、开发者、下载量、更新时间排序；侧边栏全局搜索。

**架构自动适配**：启动时检测本机架构（`runtime.GOARCH`），不兼容的应用自动过滤。

### 双模式引导与安全加固（继承 2.10.0）

**双模式初始化**：首次启动弹窗引导——**用户模式**（开箱即用，默认启用官方源）与**极客模式**（彻底禁用内置官方源，手动添加自建服务端），任何人拿到服务端即可另起炉灶。

**源管理越权拦截**：应用未完成初始化前，后端直接拦截修改/添加源的请求。

**独立自更新隔离**：即使极客模式禁用了官方源，自更新检测（`/api/check-update`）依然可达官方源，客户端永不"断联"。

### 首页数据看板与动态交互（继承 2.10.0）

磨砂玻璃数据看板（总应用/已安装/可更新）；轮播图 5 秒自动切换、悬停暂停；支持 `app:` / `tag:` / `url:` / `tab:` 定向跳转；30 分钟缓存 TTL + 弱网防丢容错，断网不清空本地数据。

### 系统级定向消息推送（继承 2.10.0）

WebSocket 实时推送 + `/api/push/pending` 离线补拉；轻提示 / 强弹窗 / 强制更新三种形态；本地去重防骚扰。

### 官方安装链路与底层管理（继承 2.10.0）

**双段式安装**：下载段完成后走飞牛官方 `app-center/v1`（`download/task` → `install/info` → `install/task` → `install/status`），真实进度回显。

**安装前依赖预检**：解包 FPK 读取 `install_dep_apps`，缺失依赖提前弹窗引导。

**强力修复幽灵应用**：一键物理清理底层目录与进程并重新注册。

**配置备份与恢复**：`@appdata` 一键打包 `.zip` 下载 / 上传恢复。

**一键诊断日志**：自动收集底层安装状态、运行状态与最近 500 行日志。

## 🧭 界面介绍

左侧导航栏共 5 项，窄屏折叠为单图标，移动端折叠为汉堡菜单。

### 🏠 首页

顶部数据看板、自动轮播图（定向跳转）、公告记录（未读红点）、四列快捷卡片（已安装 / 可更新 / 热度榜 Top 10 / 新应用）。

### 📦 应用

工具栏（状态 + 应用数 + 排序 + 手动安装 + 一键强刷）；应用详情含大图标、元信息、预览轮播、评分、启动/停止、修复、配置备份恢复等全套工具。

### ✨ 开发者

3D 球面可视化开发者，星星大小与应用数挂钩，支持拖动旋转、滚轮缩放、悬停查看。

### 🔗 源管理

添加、删除、启用、禁用、测试三方源；"极客模式"下的核心入口；官方源地址隐藏显示。

### ⚙️ 设置

通用（深色模式、导出日志）、收藏、系统（版本 / 架构 / 检查更新）、关于（源码、交流群、问题反馈、建源指南）。

## 🖥️ 服务端信息

客户端需要配合 **FN软仓服务端** 使用。**推荐搭配 v2.10.4 及以上服务端**：客户端 2.11.0 的"实时选线"体验依赖服务端的健康探测排序与 `/apps/` 302 现场选线能力。

**服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.4`

**服务端仓库**：<https://gitee.com/hhxs2025/fn-appstores>

服务端 2.10.4 的核心能力：

**动态候选下发**：返回经健康检查与实测测速排序后的 `download_urls` 数组，按健康度排序、坏的靠后。

**`/apps/` 实时选线代理**：本地文件直接 200 返回；GitHub 直链应用现场挑选最优加速规则 302 重定向，命中本地缓存的更快。

**加速器健康检查**：智能探测速度与状态，自动升降级排序。

**轮播图协议 / 定向推送 / 设备统计**：与客户端完整配合。

> 提示：客户端 2.11.0 已不再向服务端上报"线路失败"，线路排序完全由服务端自身健康探测驱动，无需客户端配合。
