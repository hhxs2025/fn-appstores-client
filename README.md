## 📖 应用简介

FN软仓是飞牛 OS 上的第三方应用商店客户端，支持**多软件源聚合**。用户可以自由添加自托管服务端地址，浏览、安装、更新飞牛官方应用中心没有的三方应用。

- **项目地址**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)
- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.9.2`
- **平台**：飞牛 OS
- **架构**：x86 / ARM 双架构兼容
- **开源协议**：MIT

> **架构支持说明**：单 fpk 内含 `fn-appstores-client-amd64` 与 `fn-appstores-client-arm64` 双二进制，`cmd/main` 按 `uname -m` 自动选择。安装逻辑已适配用户卷（`/vol*/@appcenter`）与系统分区（`/usr/local/apps/@appcenter`），支持 `install_type = root` 应用。
>
> **微应用支持**：v2.9.0 起声明 `micro_app=true`，可在飞牛应用中心宿主环境内加载，跟随系统主题。

> **✅ v2.9.3 重要改进**：**应用管理与本地回滚 + 全链路前端功能补全**。新增**停止 / 启动 / 重启 / 卸载**应用管理按钮（已安装应用详情页）；新增**升级失败自动回滚**（本地备份 FPK，不依赖服务端保留旧版）；新增**加速器池手动刷新**（设置页一键触发）；新增**静态资源版本号自动管理**（Go 每次请求首页实时计算 JS/CSS 最新修改时间，彻底告别手动改版本号 + 硬刷新）；新增**应用收藏**、**按开发者排序**、**公告未读红点**；使用指南支持移动端。

> **⚠️ v2.9.0 重要提示**：v2.9.0 修复了**应用更新功能从未生效**的历史遗留问题（飞牛官方 CLI 没有 `update` 命令，`install-fpk` 对已安装应用是空操作），并把版本读取源从磁盘 manifest 改为飞牛内部数据库。**v2.8.4 及以前的所有版本，应用更新功能均未真正生效**，请务必升级到此版本或更高版本。

## ✨ 核心功能

### 应用管理

- **多源聚合**：从所有启用的软件源并发拉取应用列表，按 `id@platform` 自动去重
- **树状聚合**：官方源可聚合多个三方源应用，无需手动添加即可发现更多应用
- **分类筛选**：15 个固定分类 + Docker/原生类型筛选 + 按源筛选
- **排序**：支持按名称、**开发者**、下载量、更新时间排序（v2.9.3 新增按开发者排序）
- **全局搜索**：侧边栏顶部搜索框，任意页面可直接搜索
- **架构自动适配**：启动时检测本机架构，不兼容的应用自动过滤

### 应用安装与更新

- **应用更新真正生效**：走飞牛 `stop → uninstall → install-fpk` 完整流程，卸载时飞牛自动保留 `@appdata` 用户数据目录，更新前后用户数据零损失
- **版本读取源修复**：从飞牛 `appcenter-cli list`（内部数据库）读实际安装版本，不再依赖可能与数据库不同步的 manifest 文件；辅以 `fixManifestVersion` 在装完后主动同步 manifest，保持数据一致
- **CLI 版本读取缓存**：`appcenter-cli list` 加 5 秒内存缓存，一次安装流程内的 5~6 次读取合并为 1 次；装完后主动 invalidate
- **下载链路打通**：客户端不二次展开候选，服务端下发的候选列表直接用；主源地址永远排第 1，兼顾统计和 302 兜底
- **候选数量与重试次数匹配**：重试次数按候选数动态计算（上限 8，保底 3）
- **失败上报闭环**：客户端上报失败时带 URL，服务端能反查规则并降权
- **手动安装**：支持本地 FPK 上传，显示完整安装日志；支持带向导的 FPK
- **多线路下载**：从服务端获取候选 URL 列表（`download_urls` 数组），依次尝试
- **三层加速兜底**：服务端候选 + 服务端加速器池 + 客户端内置加速器池
- **加速器本地学习**：本地记录每条线路对当前 NAS 的成功/失败次数，按成功率排序
- **主源地址优先**：主源地址在候选列表中永远排第 1，不参与本地学习排序
- **智能切线路**：首块 5 秒速度检测（低于 100KB/s 自动切）+ 30 秒 stall 检测
- **实时进度**：WebSocket 推送下载进度、速度、当前尝试线路等信息
- **完整性校验**：gzip 魔数 + HTML 错误页检测 + hash/size 校验（服务端提供时启用）
- **Docker 应用验证**：容器必须 `running` 才算成功，失败自动清理残留容器
- **依赖缺失引导**：识别飞牛返回的依赖缺失报错，一键跳转飞牛应用中心安装依赖
- **🆕 升级失败自动回滚（v2.9.3）**：每次安装成功后将 FPK 缓存到 `DataDir/rollback/`（每个应用只留最新 1 个）；升级失败时自动卸载新版并重装备份，日志出现 `[rollback] ✅ 回滚成功`
- **客户端自更新**：设置页一键检测最新版本，下载后引导手动安装

### 🆕 应用管理操作（v2.9.3 新增）

- **停止**：`appcenter-cli stop`，停止后应用无法访问，可随时重新启动
- **启动**：`appcenter-cli start`，已运行的应用会直接返回成功
- **重启**：`stop → 轮询等停止（最多 10 秒）→ start`，全程同步阻塞，几秒内返回结果
- **卸载**：`stop → 等停止 → uninstall`，飞牛系统默认保留 `@appdata` 用户数据；操作成功后会顺手清理该应用的回滚备份
- **UI 位置**：仅在**应用详情页**，且**仅对已安装应用**显示 4 个按钮（未安装应用不显示）
- **防重复点击**：操作期间全部按钮 disabled，且按钮文字改为「停止中...」等提示
- **二次确认**：卸载 / 重启 / 停止均有 confirm 二次确认

### 应用评分

- **5 星评分**：详情页内点击星星打分，本地记录"我的评分"
- **评分展示**：应用卡片名称右侧内联显示平均分（★ 4.5）
- **用户身份聚合**：通过统一网关注入的 uid 识别用户，回退到本地 client_id

### 🆕 应用收藏（v2.9.3 新增）

- **一键收藏**：应用卡片右上角 ☆ 或详情页「收藏」按钮
- **本地持久化**：收藏列表存 `localStorage`，不依赖服务端
- **设置页收藏列表**：设置 → 收藏 tab，显示所有收藏应用的图标、名称、作者、版本、安装状态
- **点击跳转**：点收藏项直接跳到应用详情
- **清空收藏**：设置页顶部「清空收藏」按钮（带二次确认）

### 软件源管理

- **添加/删除/启用/禁用**：填写名称和地址，测试连通性后添加
- **状态检测**：源列表显示在线/离线/已禁用，状态缓存 5 分钟
- **官方源保护**：官方源不可删除，地址隐藏显示
- **官方源地址自动迁移**：老用户升级后自动替换内置源地址

### 🆕 加速器池手动刷新（v2.9.3 新增）

- **位置**：设置 → 通用 → 「刷新加速器池」
- **行为**：忽略 24h TTL，删除本地 `accelerators_pool.json` + 清内存缓存，从官方源强制重拉
- **日志**：`[accel-pool] 收到手动刷新请求` + `[accel-pool] ✅ 刷新成功: version=xxx prefixes=N`

### 界面与体验

- **飞牛统一网关**：通过 `/app/fn-appstores-client` 访问，复用飞牛登录态，自动适配 HTTPS
- **系统主题跟随**：
  - 单个「深色模式」开关，逻辑直观
  - 默认自动跟随飞牛系统主题
  - 用户手动切换后进入手动模式，设置页出现「恢复跟随系统」小链接
  - 双通道监听：**2 秒轮询 `getPlatformConfig()` 兜底 + `$on('os/theme')` 事件加速**
- **HTTPS 图片代理**：HTTPS 页面下 HTTP 图片自动走同源代理
- **开发者星球**：3D 球面可视化开发者，拖动旋转、滚轮缩放、悬停查看
- **深色/浅色主题**：一键切换，偏好保存至浏览器
- **🆕 公告未读红点（v2.9.3）**：首页公告列表左侧显示红点，未读项标题加粗，点击查看详情后红点消失；已读状态本地持久化（最多保留最近 500 条）
- **🆕 静态资源自动版本号（v2.9.3）**：改 JS/CSS 保存后 **F5 即生效**，不用重启应用、不用勾 Disable cache、不用手动改 `?v=`
- **🆕 使用指南移动端适配（v2.9.3）**：`static/docs/readme.html` 优化手机端显示，表格横向滚动、目录 chips 横滑、悬浮回到顶部按钮

## 🖥️ 服务端信息

客户端需要配合 **FN软仓服务端** 使用，服务端负责聚合应用列表、下发候选下载地址、维护加速器规则、公告和轮播图。

- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.9.2`
- **服务端仓库**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)

服务端 v2.9.2（配套客户端 v2.9.3）的核心能力：

- **候选 URL 列表下放**：`/api/apps` 与 `/api/app/:id` 返回 `download_urls` 数组（主源 + 5 条加速器 + 原始兜底）
- **主源半托管 / fnrc 聚合源候选展开**：`buildDownloadCandidates` 会为主源半托管和 fnrc 聚合源展开加速器候选
- **302 优先 online**：`applyAccelerator` 两轮遍历，优先落 online 线路，degraded 兜底
- **加速器健康检查**：5 秒探测窗口 + 100KB/s 阈值，分 online / degraded 两档
- **失败上报接收**：`/api/accelerator/report-failed` 接收客户端上报，动态调整规则
- **仪表盘分栏**：本地源 / 聚合源分开统计
- **开发者聚合系统**：`fnrc.json` 三层生态，第三方开发者零服务器成本接入
