## 📖 应用简介

FN软仓是飞牛 OS 上的第三方应用商店客户端，支持**多软件源聚合**。用户可以自由添加自托管服务端地址，浏览、安装、更新飞牛官方应用中心没有的三方应用。

- **客户端项目地址**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)
- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.8.3`
- **平台**：飞牛 OS
- **开源协议**：MIT

> **⚠️ 架构说明**：v2.8.4 目前**仅推荐 x86 设备使用**。ARM 设备安装应用存在兼容性问题（正在排查），请等待后续版本。

## ✨ 核心功能

### 应用管理

- **多源聚合**：从所有启用的软件源并发拉取应用列表，按 `id@platform` 自动去重，保留较新版本
- **树状聚合**：官方源可聚合多个三方源应用，用户无需自行添加即可发现更多应用
- **应用类型筛选**：按「全部 / Docker应用 / 原生应用」分类
- **按源名称筛选**：下拉框快速过滤特定来源的应用
- **分类标签**：影音、办公、下载、AI、设计、社交、网络、工具、生活、商务、教育、效率、开发、游戏
- **排序**：支持按名称、下载量、更新时间排序
- **全局搜索**：搜索框置于侧边栏顶部，任意页面可直接搜索应用，输入防抖 250ms
- **一键加载全部**：取消分页，应用列表一次加载全部，滚动查看
- **架构自动适配**：启动时检测本机架构，不兼容当前设备的应用自动过滤

### 安装与更新

- **一键安装**：支持安装向导、环境变量填写
- **实时进度**：WebSocket 推送下载进度、速度、已下载/总大小
- **独立进度弹窗**：大图标 + 大百分比数字 + 速度详情，成功自动关闭
- **一次性下载**：单次 GET 完整下载，不依赖 HEAD / Content-Length / Range，适配外链托管（Gitee 等）
- **格式校验与重试**：下载后校验 gzip 魔数，非有效 FPK 自动重试（最多 3 次）
- **🆕 手动安装入口**：应用页工具栏「手动安装」，支持本地 FPK 上传，弹窗显示 `install-fpk` 完整输出，便于调试排查
- **🆕 上传/安装进度**：手动安装支持上传进度（XHR 原生）+ 安装进度（渐近式假进度 + 已用时提示）
- **安装结果验证**：Docker 应用必须容器 `running` 才算成功
- **失败自动清理**：Docker 容器启动失败时清理残留容器
- **客户端自更新**：设置页一键检测最新版本，下载 FPK 后引导手动安装

### 应用评分

- **5 星评分**：应用详情页内点击星星打分
- **本地记录**：记录「我的评分」，再次打开显示已评星级
- **评分展示**：应用卡片名称右侧内联显示平均分（★ 4.5）

### 软件源管理

- **添加/删除**：填写名称和地址，测试连通性后添加
- **启用/禁用**：三方源可随时启用或禁用
- **状态检测**：源列表显示在线/离线/已禁用，状态缓存 5 分钟
- **官方源保护**：官方源不可删除，地址隐藏显示
- **官方源地址自动迁移**：内置官方源地址更新后，老用户升级自动替换

### 界面与体验

- **飞牛统一网关**：通过 `/app/fn-appstores-client` 路径访问，复用飞牛登录态，自动适配 HTTPS

- **应用卡片精简**：只保留图标、名称、评分、分类来源、按钮
- **应用详情页**：主内容区切换，带 ← 返回按钮，不丢失列表状态

## 🖼 轮播图双链路兜底说明

### 适用场景

家宽 v6 和 frp v4 分属不同端口（如 v6 监听 1666、frp 穿透 8888），无法在一个域名下做双栈。想让"有 v6 的手机走家宽、没 v6 的手机自动降级到 frp"。

### 配置方式

在服务端 `notice.json` 的 `carousel` 数组中，每个 URL 用 `|` 分隔首选地址和备用地址：

```json
"carousel": [
  "http://[家宽v6地址]:1666/1.webp|http://frp域名:8888/1.webp",
  "http://[家宽v6地址]:1666/2.webp|http://frp域名:8888/2.webp"
]
```

**格式规则**：

- 左侧：首选地址（v6 家宽）
- 右侧：备用地址（v4 frp）
- 中间用竖线 `|` 分隔，**不加空格**
- IPv6 字面量地址要用方括号 `[...]` 包裹
- 旧格式（单个 URL 不带 `|`）**完全兼容**

### 前端行为

- 页面加载时先请求首选地址
- 首选地址加载失败（onerror）→ 自动切换到备用地址
- 两个都失败 → 隐藏该轮播图，不显示破图
- 点击放大弹窗同样支持逐级降级

## 📥 下载策略说明

### 当前策略：一次性 GET

FPK 文件下载采用**单次 GET 完整下载**，不发送 HEAD、不依赖 `Content-Length`、不使用 `Range`。

**为什么这么设计**：客户端通过服务端 302 跳转到 Gitee 等外链托管平台下载。Gitee 的 CDN（Varnish）在文件首次被访问时处于"回源"状态：

- HEAD 可能不返回 `Content-Length`
- GET 可能返回错误页而非完整文件（约几十字节）
- 缓存预热后（几十秒到几分钟）才恢复正常

一次性下载 + gzip 魔数校验 + 最多 3 次重试，能自动跨过这个冷启动窗口：

1. 首次 GET → 拿到错误页（非 gzip）
2. 校验失败 → 等 2 秒后重试
3. 第二次 GET → CDN 已预热 → 拿到完整 FPK → 校验通过 → 解压安装

### 进度显示自适应

- `Content-Length` 已知（CDN 已缓存）：`1.2 MB/s · 3.2 MB / 8.5 MB`，百分比正常走动
- `Content-Length` 未知（CDN 冷启动）：`1.2 MB/s · 已下载 3.2 MB`，百分比保持 0%

两种情况下用户都能看到下载在**推进**，不会卡死在 `-0.0 MB`。

## 🔍 Docker 应用安装说明

Docker 应用的安装流程包含拉镜像、创建容器、启动容器三步。大镜像（几百 MB ~ GB）在国内拉取可能需要几分钟到十几分钟，且容易因端口冲突、权限不足等原因失败。

**客户端侧的行为**：

- **容器必须 `running` 才算成功**：创建但未启动（`Created`）、启动即退出（`Exited`）、容器未创建（`no_container`）都会被明确报错
- **失败自动清理**：避免留下 `Created` 状态的孤儿容器，用户可直接重试
- **错误信息更明确**：端口冲突报"端口已被占用"，权限问题报"权限不足"，镜像问题报"镜像不存在"

**安装大镜像应用时的建议**：

- 不要关闭客户端页面（WebSocket 断开后进度不可见，但后端会继续跑完）
- 遇到"端口已被占用"，进入应用卸载后重装，在向导中换一个未被占用的端口

## 🛠 手动安装说明（v2.8.4 新增）

应用页工具栏「手动安装」按钮，支持上传本地 FPK 直接安装，主要用于调试和排查故障。

**使用步骤**：

1. 应用页工具栏 →「手动安装」
2. 选择本地 FPK 文件
3. 点「开始安装」
4. 弹窗显示上传进度和安装进度
5. 完成后展示 `install-fpk` 完整 stdout/stderr 日志

**用途**：

- 避免反复从外链下载（防止 Gitee 限流）
- 排查安装失败原因（显示飞牛 CLI 的完整输出）
- 测试刚打包的 FPK，无需先上传到软件源

## ❓ 常见问题

<details>
<summary><b>安装应用提示"未配置默认安装位置"？</b></summary>

这是飞牛 `install-fpk` 的行为。请前往 **飞牛应用中心 → 设置 → 应用下载和安装位置**，选择一个默认存储空间（不要选"安装前询问"），然后再从软仓安装。
</details>

<details>
<summary><b>应用装了一次之后重装失败？</b></summary>

v2.8.4 已修复此问题。如果你的软仓还是旧版本，请：
1. 升级到 v2.8.4
2. 在飞牛应用中心手动卸载该应用（清掉旧状态）
3. 从软仓重新安装
</details>

<details>
<summary><b>ARM 设备安装全部报"安装目录不存在"？</b></summary>

v2.8.4 已知问题，正在排查。**临时方案**：ARM 用户请通过**飞牛应用中心手动安装**，不用软仓。
</details>

<details>
<summary><b>升级客户端后，之前添加的源还在吗？</b></summary>

v2.5.1+ 已修复。`sources.json` 存储于 `TRIM_PKGVAR` 持久化目录，应用更新后配置不会丢失。
</details>

<details>
<summary><b>手动安装上传卡住？</b></summary>

- 检查 FPK 文件大小（大文件上传需要时间）
- 检查客户端与服务端网络
- 查看 `app.log` 是否有服务端异常
</details>

<details>
<summary><b>安装日志在哪里看？</b></summary>

- **客户端日志**：`/vol*/@appdata/fn-appstores-client/app.log`
- **飞牛 CLI 输出**：包含在客户端日志的 `📋 install-fpk stdout:` 段
- **飞牛应用中心日志**：`sudo journalctl -u trim_app_center.service -f`
</details>
