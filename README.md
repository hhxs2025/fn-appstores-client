## 📖 应用简介

FN软仓是飞牛 OS 上的第三方应用商店客户端，支持**多软件源聚合**。用户可以自由添加自托管服务端地址，浏览、安装、更新飞牛官方应用中心没有的三方应用。

- **项目地址**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)
- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.0`
- **平台**：飞牛 OS
- **架构**：x86 / ARM 双架构兼容
- **开源协议**：MIT

> **架构与机器码识别说明**：v2.9.4 起，客户端会优先读取飞牛底层系统注入的机器码（`TRIM_SYS_MACHINE_ID`）作为设备唯一标识，确保**重装系统后不产生虚假新设备**。同时，系统架构（如 `fnos-amd64`）通过请求头精准上报，解决 WebView 读取 `UA` 显示 Win32 的历史遗留问题。

> **✅ v2.9.5 (重制版) 核心变化：极速下载、底层重构与系统级消息推送**。
> 客户端新增**“5 秒首包防假死”**机制，彻底解决 GitHub 直链应用下载长期卡 0% 的痛点；全面接入飞牛官方 `app-center/v1` API 实现真实进度与平滑升级；并新增**“定向消息推送接收与强制更新拦截”**，无缝承接服务端下发的运营通知与重要告警。

## ✨ 核心功能

### 应用管理

- **多源聚合**：从所有启用的软件源并发拉取应用列表，按 `id@platform` 自动去重
- **树状聚合**：官方源可聚合多个三方源应用，无需手动添加即可发现更多应用
- **分类筛选**：15 个固定分类 + Docker/原生类型筛选 + 按源筛选
- **排序**：支持按名称、**开发者**、下载量、更新时间排序
- **全局搜索**：侧边栏顶部搜索框，任意页面可直接搜索
- **架构自动适配**：启动时检测本机架构（`runtime.GOARCH`），不兼容的应用自动过滤

### 系统级定向消息推送（v2.9.5 新增）

- **多端触达机制**：支持 WebSocket 实时接收服务端推送，同时在客户端启动时通过 `/api/push/pending` 主动拉取离线期间的未读消息，确保不漏看。
- **三种消息形态**：
  - **轻提示 (Toast)**：停留长达 10 秒，且**鼠标悬停时自动暂停倒计时**，排版清晰，适合日常运营通知。
  - **强弹窗 (Modal)**：必须在页面中央点击“我知道了”才能关闭，适合重要版本发布或紧急故障通告。
  - **强制更新 (Force Update)**：直接锁定页面，提供“一键下载最新 FPK”引导。下载完成后提示去飞牛应用中心覆盖安装，解决旧版本严重 Bug 或安全漏洞。
- **本地去重与防骚扰**：接收过的推送会被记录在浏览器本地，刷新页面不会重复弹出。

### 应用安装与更新

- **双段式安装链路**：
  - **下载段**：客户端调 `/api/download`，后端下发**最多 14 条**基于实测速度动态排序的候选线路；客户端加入 **5 秒首包看门狗**（如果加速器假死无响应，5 秒内强制切断并切换下一条），配合 30 秒 stall 检测与首块 5 秒速度检测，彻底告别下载卡 0%。
  - **安装段**：FPK 下载到本地后，前端调飞牛官方 `app-center/v1` 完成安装——`download/task` 登记本地文件 → `install/info` 预检依赖与读取向导 → `install/task` 提交安装 → `install/status` 轮询获取真实进度。
- **安装前依赖预检**：安装前调 `/api/read-manifest` 解压 FPK 读 `install_dep_apps`，主动与飞牛已安装应用对比，缺失依赖直接弹窗引导。
- **真实安装进度**：轮询 `install/status` 的 `progress` 字段，进度条与实际安装状态同步。
- **平滑更新**：走飞牛 `update/task` 更新接口，系统自动保留用户数据并平滑升级，不再使用"卸载 → 重装"粗暴流程。

### 底层管理与强力修复

- **智能状态联动**：应用详情页打开时，自动调用底层接口查询真实运行状态。运行中只显示「停止」，已停止只显示「启动」，不再无脑全显。
- **强力修复（专治幽灵应用）**：针对部分设备因底层数据库卡死导致的"应用中心有，桌面无图标/点不开"现象。一键绕过飞牛 CLI 安全拦截，强制物理清理底层目录与进程，并重新注册安装。
- **配置备份与恢复**：
  - **备份**：将 `/vol/@appdata/{app_id}` 下的所有用户配置打包为 `.zip` 下载至本地。
  - **恢复**：上传 `.zip` 备份文件，自动解压覆盖并重启应用。重装系统后数据一键找回。

### 设备与架构精准识别

- **机器码采集**：读取系统底层 ID，配合服务端实现 100% 精确的设备活跃统计与去重。
- **全链路 Header 注入**：客户端向服务端发起请求时（拉应用、看公告、拉消息），自动附带 `X-Client-ID`、`X-Device-Type`（如 `fnos-amd64`）和 `X-App-Version`。
- **真实架构显示**：调用 `/api/sysinfo` 获取 NAS 真实 CPU 架构，彻底告别浏览器兼容性导致的显示错误。

### 一键诊断日志

- **位置**：应用详情页新增「导出日志」按钮。
- **内容**：自动收集飞牛底层的安装状态、运行状态，以及 `@appdata` 目录下最后 500 行 `.log` 日志。
- **价值**：遇到"启动失败"或"安装报错"时，生成 `.txt` 报告一键发给开发者，告别"黑盒盲猜"排查。

### 软件源与系统体验

- **源管理**：支持添加、删除、启用、禁用、测试三方源；官方源不可删除。
- **加速池手动刷新**：设置页一键触发，忽略 TTL 限制强制拉取最新加速节点。
- **系统主题跟随**：默认自动跟随飞牛系统，2 秒轮询 `getPlatformConfig()` 兜底，支持手动深色模式。
- **静态资源自动版本号**：每次请求首页自动计算静态文件 Hash 后缀，改 JS/CSS 后 F5 即生效，告别强刷。
- **公告未读红点**：首页公告列表支持已读标记，红点提示，本地持久化。

## 📜 版本记录

### v2.9.5 (重制版)

**全新底层 API 接入 + 极速下载体验 + 定向推送接收**

**✨ 核心变化**

- **消息推送与强更拦截**：新增 WebSocket 监听与 `/api/push/pending` 接口，支持离线拉取。客户端可接收 `toast` / `modal` / `force_update` 三种指令。强更会直接阻断页面操作并提供 FPK 下载通道，彻底解决旧版本客户端无法被通知的问题。
- **下载与加速器重构**：彻底解决 GitHub 直链应用卡 0% 的问题。服务端下发最多 12 条智能测速排序线路；客户端摒弃旧的本地历史重排逻辑，完全信任服务端顺序，并新增 **“5 秒首包看门狗”**（遇到加速器假死 5 秒内无数据自动切断换下一条），极大提升下载成功率。
- **安装走官方 API**：安装不再依赖 `appcenter-cli install-fpk`，改为飞牛官方的 `app-center/v1` REST 接口：`download/task` 登记本地 FPK → `install/info` 预检依赖与读向导 → `install/task` 提交 → `install/status` 轮询进度。
- **更新与卸载走官方 API**：从以往的粗暴流程，改为 `update/task` 平滑更新（自动保留数据）；卸载改为 `uninstall/task` 轮询。

**🔧 行为变化**

- **真实安装进度**：轮询 `install/status` 的 `progress` 字段，进度条与实际安装状态同步。
- **依赖预检提前**：改为安装前调 `/api/read-manifest` 主动预检，缺失依赖直接弹窗。
- **向导数据源切换**：向导配置改为从飞牛官方 `install/info` 返回读取，参数通过 `install/task` 的 `customParameters` 提交。

**🔒 安全与体验修复**

- **安全加固**：客户端加入 `APIProxyImage` 目标 IP 解析校验（防 SSRF 探测）；服务端增加并发数据锁、设备统计防刷、并发防污染及流式备份防 OOM。
- **状态同步修复**：修复后台管理面板首次打开需手动刷新的时序问题，彻底解决安装后状态不变或卸载后残留“幽灵应用”的问题。

**🔌 兼容性**

- **服务端 v2.10.0 配套最佳**（提供 `/api/download`、`/api/push/pending` 等接口）。
- **旧版服务端**：若无推送接口，客户端捕获 404 后静默跳过，不干扰正常使用；若无下载接口，前端提示"服务端版本过低，请升级"。
- **飞牛系统**：要求飞牛 OS 提供 `app-center/v1` 接口。

### v2.9.4

**全链路身份识别 + 一键诊断 + 底层管理增强**

**✨ 新增**

- **设备身份与架构识别**：新建 `device.go` 及 `APISysInfo` 接口。客户端启动时生成 `ClientID`，每次网络请求注入 `X-Client-ID` 与 `X-Device-Type`。完美对接服务端的精准统计系统。
- **一键诊断日志导出**：新建 `diagnostics.go` 及 `APIDiagnostics` 接口。一键抓取应用底层 `status` 状态与 `@appdata` 的最后 500 行 `.log`，直接下载 `.txt` 报告。
- **智能状态联动**：`apps.js` 详情页加载时请求 `/api/app/:app_id/status`，根据返回状态动态隐藏/显示「启动」和「停止」按钮。
- **幽灵应用强力修复**：`manage.go` 新增 `APIRepairApp`。针对飞牛底层数据库卡死导致"无图标/点不开"的应用，直接物理清理 `/var/apps` 及残留目录，强杀进程，重新注册安装。
- **配置备份与恢复**：新建 `backup.go`，新增 `/backup` 与 `/restore` 接口。支持打包与解压 `@appdata` 目录，实现 NAS 玩家梦寐以求的配置无损迁移。
- **安装静默轮询**：`websocket.js` 在收到安装成功指令后，不再死等 12 秒，改为每 3 秒轮询一次 `/api/installed`，系统注册完毕后瞬间刷新界面。

**🐛 修复**
- 修复 WebView 环境下读取浏览器 UA 导致"系统架构"显示为 Win32 的问题，改为直接调用 Go 底层的 `/api/sysinfo` 返回真实架构。
- 修复部分网络环境下应用安装后底部状态栏不更新的问题。

### v2.9.3

**应用管理与本地回滚 + 全链路前端功能补全 + 缓存自动管理**

**✨ 新增**
- **应用管理**：停止/启动/重启/卸载 4 个按钮。
- **本地回滚**：升级失败自动卸载新版并重装本地缓存备份。
- **加速池手动刷新**：设置页一键强刷。

- **应用收藏 / 开发者排序 / 公告未读红点 / 指南移动端适配**。

### v2.9.0 及更早

## 🖥️ 服务端信息

客户端需要配合 **FN软仓服务端** 使用，服务端负责聚合应用列表、下发候选下载地址、维护加速器规则、公告和轮播图。

- **服务端镜像**：`docker pull ccr.ccs.tencentyun.com/hhxs2025/fn-appstores-server:2.10.0`
- **服务端仓库**：[https://gitee.com/hhxs2025/fn-appstores](https://gitee.com/hhxs2025/fn-appstores)

服务端 v2.10.0（配套客户端 v2.9.5）的核心能力：

- **定向消息推送**：后台支持向“指定版本”（如 2.9.4）、“指定架构”（如 ARM）或“指定设备 ID”发送轻提示、弹窗或强制更新指令。
- **开发者纯在线托管**：开发者无需维护 Gitee 仓库，数据保存在服务端本地。
- **应用变更审核**：开发者每次保存应用均需源主审核后上线。
- **设备精准统计**：内置 `devices` 数据表，支持在线状态判定与 CSV 导出，新增按版本、按架构筛选查看明细。
- **动态候选下发**：`/api/apps` 与 `/api/app/:id` 返回实测测速后的 `download_urls` 数组（最多 14 条）。
- **加速器健康检查**：智能探测速度与状态，支持降级/离线兜底，并在后台展示实时速度排名。
- **FPK 下载任务管理**：`/api/download` + `/api/download/status` 提供后端多线路下载能力。
- **FPK 依赖预读**：`/api/read-manifest` 解压 FPK 读取 manifest 依赖。
